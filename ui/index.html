中継経路の詳しい説明

Gateway が Desktop とモデルホストの通信を中継します。同時接続数の上限はこの Hub 経由の通信に適用します。モデルのロード・生成・停止はホスト側が管理します。

従来の接続先URLとトークンを手動設定する構成向けです。端末ネットワークを使う場合、この手動サーバーの開始は不要です。両方を同時には開始できません。

モデルの確認と同時接続数の詳しい説明

Hub はモデル一覧・接続状態・管理者の設定に基づいて接続先を選びます。未ロードでも一覧にあれば割当候補になります。生成の成功はホスト側の設定と応答によります。同じホストなど、同時接続数を共有したい接続先は同じグループ（容量プール）にまとめます。
