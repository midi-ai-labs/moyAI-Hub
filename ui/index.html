モデル状態と実行枠の詳しい説明

モデル一覧への掲載とロード状態は別の情報です。ホストが報告しないロード状態は推測しません。ロード済み表示も生成の成功を保証しません。同じ GPU を使うホストは同じ実行枠グループ（容量プール）にまとめます。上限は Gateway 経由の要求に適用します。

接続している端末はありません

サーバーを開始し、対応クライアントを登録すると、ここに表示されます。

端末の状態は Desktop からの申告です。「操作待ち」に戻っても、接続先の処理が続く場合があります。上の実行状況で「上流終了確認待ち」を確認してください。

端末の識別と生存確認について

IP は表示情報であり、端末の識別と認証には専用 ID とトークンを使います。30 秒間の生存確認（heartbeat）がない端末は切断として表示します。サーバー再起動時には再登録が必要です。
