# HubからMCP履歴を確認する

Hubの「MCP履歴」では、参加端末に保存された記録を読み取り専用で確認できます。「接続端末」の「履歴を見る」からも、その端末を選んで開けます。タスク受付がOFFでも、Hubへ接続しているDesktopの履歴を取得できます。

1. 端末と「MCP指示」または「MCP実行」を選び、「履歴を取得」を押します。
2. 一覧で依頼の概要、相手端末、対象、状態、記録日時を確認します。古い履歴はページを切り替えて取得します。
3. 「詳細を見る」で記録された指示、ツール実行、エラー、結果等のMarkdownを確認します。
4. 「Markdownで保存」で新しい `.md` ファイルを保存します。表示中に取得した詳細を保存し、同名の既存ファイルには上書きしません。保存先選択をキャンセルしても履歴は変わりません。

「MCP指示」はその端末が依頼した仕事、「MCP実行」はその端末で受け付けた仕事です。実行側の完了と、指示側が結果を受け取ったことは別です。Hubには取得日時と端末の接続状態を表示し、取得済みの記録を現在の実行状態として扱いません。実行や停止の操作は各Desktopで行います。

取得は最大60秒で期限切れになります。端末が未接続の場合や、この機能に対応しない旧版Desktopでは、新しく取得できません。参加は許可されたまま「新規利用の停止」になっている端末は、診断用の読み取りを継続できます。失効した端末や期限切れの端末資格からは取得しません。

Hubに取得した結果はメモリ上で最大64件・30分間保持します。端末が未接続でも取得済みの記録を確認できますが、Hub再起動後は消えます。履歴の保存元は各Desktopです。Hubの詳細はMarkdown本文を最大64 KiBまで取得し、省略がある場合は明示します。全体の確認・保存は元のDesktopの「MCP履歴」で行ってください。

## 通信と保存の境界

閲覧要求はHubのローカルTauri管理画面だけが作成します。Desktopは既存の相互TLS接続で自端末への要求を受け取り、ローカルの履歴だけを返します。この機能のためにDesktopへ待受ポートや証明書入力を追加する必要はありません。公開MCPツールや他の参加端末から、管理者用の履歴要求を作成したり、別端末の結果を読むことはできません。

`GET /v1/network/history/requests` と `POST /v1/network/history/results` は証明書で認証した自端末に限定します。要求は端末・方向・ページまたは履歴IDに束縛し、1端末につき同時に1件までです。返却内容は型、対象、件数、本文サイズを検証します。この返却APIだけ要求body上限を512 KiBとし、他の端末ネットワークAPIの64 KiB上限は維持します。

通常の端末間タスク実行・結果返却はDesktop同士で行います。Hubが記録本文を受け取るのは、管理者が履歴閲覧を明示した場合だけです。Hubのカタログ・端末台帳へ履歴本文を永続保存せず、モデル割当や新しい作業の実行にも流用しません。

実装の正本は `src/network/history.rs`、`src/network/api.rs`、`src/desktop/network_admin.rs`、`ui/src/history.ts` と近傍testsです。GUIと別端末での受入結果は、実施したtaskの検証記録を参照してください。
