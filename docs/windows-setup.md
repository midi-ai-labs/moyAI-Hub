# Windowsへの導入・更新・削除

Hub 1.0.1以降のWindows x64配布物に適用します。実行ファイルはPC共通、設定・資格・共有会話は起動したWindows利用者ごとに管理します。

## 導入と起動

1. ZIP全体を展開し、`Setup-Hub.cmd`を通常の権限で開きます。配置・更新の管理者承認だけ別画面で行います。
2. `%ProgramFiles%\moyAI\Hub`へ配置後、元の利用者の権限でHubを起動し、管理画面を開きます。次回からはスタートメニューの「moyAI Team Management」を使います。
3. 初期のWeb管理ポートは固定の9080です。別の固定ポートは `Setup-Hub.cmd -WebPort 9081` と指定します。使用中のポートから空きポートへ自動では切り替えません。未指定なら保存済みのポートを維持します。

設定・DB・資格情報・ログの既定保存先は `%LOCALAPPDATA%\midi-ai-labs\moyai-data\hub` です。Program Filesへ稼働データを書きません。`-HubDataDir C:\HubData`でSetupに指定した場合は、起動と初期化でも同じ保存先を明示します。CLIでは`--data-dir`、または`MOYAI_HUB_DATA_DIR`を使えます。

Setup全体を「管理者として実行」しないでください。管理者のHubプロファイルを利用者のプロファイルへ置き換えることはありません。配置先がPC共通でも、通常起動の権限と管理資格は起動した利用者のものです。Program Filesへの配置はWindowsサービス化を意味せず、サインアウト後の稼働も追加しません。

## 旧版から更新する

関連する仕事・保持アプリの停止を確認し、HubとGatewayを終了してから新配布物のSetupを実行します。PCを再起動してから更新する場合、サインイン時の自動起動で旧Hubが開始していれば停止してください。

1.0.3以降は、旧配置のWindows受信許可が残っていても保存先を移行し、管理画面を開けます。更新後に「PCの接続 → 以前の配置の受信許可 → 以前の配置を確認」で古い実行ファイル・保存先のルールを選択し、確認チェックとUACを経て解除してください。旧実行ファイルがなくても解除できます。現在の配置に必要な受信許可は、範囲を確認して別途設定します。旧ルールの自動削除・自動転用は行いません。

旧既定 `%APPDATA%\ai.midi.moyai.hub` のデータは、新既定にまだデータがない場合だけ、起動時に一度移動します。資格を二か所へ複製しません。Hub・Gatewayが稼働中、ファイルが使用中、リンクを含む、新旧両方にデータがある場合は移動せず理由を表示します。同時に起動操作を行った場合は移行完了を待ち合わせ、同じHubへ接続します。移動先が別ボリュームでrenameできない場合も自動コピーしません。独自の保存先は移動しません。

HTTPS管理の証明書・秘密鍵を旧Hub保存先の中に置いている場合は、保存済みWeb設定の該当するファイルパスも新保存先へ更新します。外部の証明書、各端末の作業フォルダー、会話本文に書かれたパスは変更しません。移行を戻す場合はWeb設定も元の内容へ戻します。

移行中・完了の状態は `%LOCALAPPDATA%\midi-ai-labs\moyai-data\migrations\hub.json`という一つの記録で管理します。端末の鍵・会話本文は記録しません。移行中に処理が終了した場合は、旧・新のどちらを明示しても起動・初期化を中止し、保存先と記録の場所を表示します。欠けた資格やカタログを新規作成しません。正常に元へ戻せた場合だけ移行中の記録を解除し、完了記録は保持します。初期化後に旧保存先が再作成されても、自動で取り込んで旧履歴や資格を復活させません。移行・初期化の排他情報は保存先の親に置き、Hubデータを削除している間の再起動を防ぎます。

## アプリの削除と保存データの初期化

`Uninstall-Hub.cmd`をダブルクリックすると、Hubのアプリ削除と保存データ初期化の範囲を選べます。コマンドの`Setup-Hub.cmd -Uninstall`も同じ削除処理を使います。導入記録と一致するHub実行物・ショートカットを削除し、初期化を選ばなければ保存データは保持します。本体の削除はこのPCの全Windows利用者に影響し、保存データの初期化は実行した利用者だけが対象です。既定ではDesktopと実行補助サービスを保持し、対話画面で追加選択した場合はその範囲も削除します。プロジェクトの作業フォルダーと、追加・変更されたファイルは保持します。

`moyai-cleanup-hub.exe`はHubの保存データを初期化します。ダブルクリックすると、対象の保存先と削除される情報を日本語で表示し、「はい／いいえ」で確認します。既定は「いいえ」です。「はい」ではHub・Gatewayと共有の仕事・保持アプリの停止を確認し、このプロファイルの自動起動を解除してからフォルダーを削除します。設定・モデル接続情報・端末の登録と鍵・共有会話・保存した成果が失われ、端末は新しいHubへ再参加する必要があります。Hub本体、Desktopデータ、各端末の作業フォルダーは削除しません。

完了後は「cleanupが正常に完了しました。終了するにはキーを押してください」と表示します。取消・稼働中・停止未確認・削除失敗では正常完了を表示せず、理由と残った場所を表示します。現在または移行前の保存先に対応する受信許可が残る場合は、新版Hub管理画面で解除してから再実行します。

## 配置成功後に起動できない場合

`%ProgramData%\moyAI\setup-results`の成功結果は、実行ファイルの配置・削除の結果です。起動の成功とは別です。Setupでの起動失敗は、元のエラー内容と`%LOCALAPPDATA%\midi-ai-labs\moyai-data\installations\logs`内のログを表示します。スタートメニューからの起動失敗もダイアログで知らせます。Hubプロセス開始後の詳細は、保存先の`hub-startup.log`を確認してください。保存先の移行より前の失敗では、このファイルがまだない場合があります。

対象確認だけなら `moyai-cleanup-hub.exe --preview`、確認画面なしの初期化は `moyai-cleanup-hub.exe --reset-user-data --confirm-delete`を使います。独自の保存先は同じ`--data-dir`も指定します。アプリと保存データを同時に取り除く場合は `Setup-Hub.cmd -Uninstall -ResetHubData`を使えます。

`Setup-Hub.cmd -Uninstall -CheckOnly`は変更せずHub本体の導入先を確認します。別のWindows利用者の保存データ・起動登録、別保存先のHub、自分で追加したファイル・独自の自動起動登録は削除対象にしません。
