# moyAI Hub v1.0.6

Windowsの配置・削除処理をDesktopと同期し、独立した配布物としての案内を整理しました。

- 手動削除後に空の配置フォルダーだけが残った場合も、Setup-Hub.cmdで再導入できます。
- 配置後のファイル検証に失敗した場合は旧componentを戻します。旧モジュールの整理では、導入記録と一致する対象だけを削除します。
- 共通実行補助サービスの明示削除は、利用中のDesktop・CLI・Runnerがいなければ残ったサービスを通常停止してから進めます。Hubの通常導入でDesktopや共通サービスを新規導入しません。
- Desktopの配布物にはHubを同梱しません。Hubを管理するPCでこの単体版を導入します。同じPCへのDesktopとHubの個別導入も可能です。

通常更新ではHubの設定、登録済み端末・接続情報、共有会話を保持します。保存データの初期化は明示的なcleanupだけで行います。[導入・更新・削除](../windows-setup.md)を参照してください。

Hub本体とWeb管理・通信の仕様は1.0.5から変更していません。Windows x64単体版にTauriやWebView2は不要です。実際に障害が起きた他の利用者のPCや、組織固有の権限設定での確認とは区別して検証します。
