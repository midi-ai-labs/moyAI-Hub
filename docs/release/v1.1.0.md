# moyAI Hub v1.1.0

管理画面で端末の接続受付を停止すると、Hubを再起動しても停止を保ちます。再開するには「接続の受付を開始」を押してください。

- 保存済みの待受IPがまだ使えない場合やポートが使用中の場合は、ローカル管理画面で原因を確認できます。Hubは2秒から最大60秒の間隔で再試行します。
- 保存済みのリモート管理用ポートや証明書に問題がある場合も、ローカルで管理を続けられます。ポートの競合を解消したり証明書を修正したりすると、Hubはリモート公開を再試行します。管理画面では、このPCで開くURLと別のPCから使うURLを区別して案内します。
- Windowsのサインアウト・シャットダウン通知を処理し、終了が取り消された場合はHubの稼働を継続します。

管理用PCでZIP全体を展開し、`Setup-Hub.cmd` を実行してください。Windows x64、x64 Visual C++ランタイム、対応ブラウザーが必要です。操作PC・実行PCには [moyAI Desktop v3.1.0 LYNX](https://github.com/midi-ai-labs/moyAI/releases/tag/v3.1.0) を導入してください。
