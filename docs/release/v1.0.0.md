# moyAI Hub v1.0.0

Windows x64単体版に、固定ポートを設定した `web-management.json` を同梱します。`Start-Hub.cmd` をダブルクリックする前に、使うポートを確認・変更できます。

## 起動設定の変更

- 保存済みのWeb設定がない初回は、`moyai-hub.exe` と同じフォルダーの `web-management.json` を読み込みます。初期値はローカル管理ポート9080、他端末向け公開OFFです。
- 別の固定ポートを使う場合は、初回起動前に同梱ファイルの `settings.local_port` を変更します。指定ポートが使用中なら起動エラーになり、空きポートへ自動では切り替わりません。
- 起動に成功した設定はHubの保存先へ保存し、次回から使います。保存済みの設定は、同梱ファイルで上書きしません。
- Hubを停止した後、`--web-port PORT` または `--web-settings FILE` で設定を明示すると、その指定を優先します。CLI用JSONの形式は同梱・保存用ファイルと異なります。

設定の形式、状態確認、終了の手順は[Web管理](../web-management.md)、チームの導入は[準備の手順](../team-preparation.md)を参照してください。

## 必要な環境と更新

Windows x64、Visual C++ x64ランタイム、通常のWebブラウザーが必要です。Hub自体にWebView2、Rust、Node.jsは不要です。DesktopとAIホストは別途用意してください。

ZIPを固定のフォルダーへ展開し、`moyai-hub.exe`、`Start-Hub.cmd`、`Stop-Hub.cmd`、`web-management.json` を同じフォルダーに置きます。初回設定を確認して `Start-Hub.cmd` を開きます。ブラウザーを閉じてもHubは稼働するため、終了には `Stop-Hub.cmd` を使います。

0.1.0から更新する場合はHubを停止し、保存先をバックアップしてから配布ファイルを交換します。Windowsの既定保存先は `%APPDATA%\ai.midi.moyai.hub` です。独自の保存先を使う場合は、起動・状態確認・終了にも同じ `--data-dir` を指定します。バックアップと復元の条件は[共有仕事の保守](../shared-work.md#保守と復元)を確認してください。

配布物のファイル一覧とSHA256は `manifest.json` と `SHA256SUMS.txt` に記録します。第三者依存の通知は `THIRD_PARTY_NOTICES.txt` を参照してください。
