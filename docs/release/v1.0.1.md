# moyAI Hub v1.0.1

Hubの実行ファイルをProgram Filesへ導入し、保存データの場所と初期化操作を整理したWindows向け更新です。

- Hub単体版とDesktop同梱版の配置先を `%ProgramFiles%\moyAI\Hub` に統一します。導入・更新・削除時だけ管理者承認し、通常起動は元のWindows利用者の権限で行います。
- 利用者データの既定保存先を `%LOCALAPPDATA%\midi-ai-labs\moyai-data\hub` に変更します。旧既定からは停止確認後に一度移動し、資格を複製せず、新旧両方にデータがある場合は統合しません。
- `moyai-cleanup-hub.exe`を追加します。ダブルクリックで日本語の削除確認を表示し、停止を確認できたHubの設定・資格・共有会話を初期化します。結果を表示してキー入力を待ちます。
- 初期Web管理ポート9080を維持し、Setupの`-WebPort`で固定ポートを指定できます。Program Files内の初期テンプレートを編集する必要はありません。
- 初期化後に旧保存先から資格や履歴を自動で再取り込みしません。Desktopデータ、導入済みモジュール、プロジェクトの作業フォルダーは保持します。

旧配置の受信許可は更新前にHub管理画面で解除してください。詳細と削除範囲は[Windowsへの導入・更新・削除](../windows-setup.md)を参照してください。
