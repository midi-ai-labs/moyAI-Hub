# moyAI Hub v1.0.4

Windowsのアンインストール処理を改善した修正版です。Hub本体の通信・管理認証・保存形式は1.0.3から変更していません。

- 一部の配布ファイルが削除されていても、削除用スクリプトと導入記録を確認できれば本体を削除できます。改変されたスクリプトや所有不明のファイルは受け入れません。
- 保存データの初期化を同時に選んだ場合は、管理者承認と削除可否の確認後、元のWindows利用者で初期化します。成功してから本体を削除するため、初期化失敗時には本体が残ります。複数製品のうち先に完了した初期化は取り消せません。
- 共通実行補助サービスを明示削除する際、既に実行ファイル・配置フォルダー・サービス登録が欠けている場合も、残存部分の所有を確認して削除します。
- Desktop 3.0.6の配布物から旧Desktopを削除する際も、その配置に一致する自動起動・接続ファイルの関連付け・ショートカットを解除します。別配置や変更された登録は保持します。

起動中のアプリは強制終了しません。Hub・Desktop・Runnerと関連する仕事を終了してから実行してください。通常の更新では保存データを初期化しません。詳しい手順は[Windowsへの導入・更新・削除](../windows-setup.md)を参照してください。
