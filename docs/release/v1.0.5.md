# moyAI Hub v1.0.5

モデルの表示名とDesktopへの変更反映を改善したWindows x64向けの修正版です。

- モデル編集の「表示名」を、Desktopのモデル選択にも使う共通の名前として保存します。「登録先の名前」は接続先を識別する名前として分け、同じモデルのほかの登録先名を変更しません。
- 古い管理画面から共通の表示名を含まない更新が届いた場合は、現在の表示名を保持します。競合した更新や空の表示名は保存せず、保存後の再起動でも名前を維持します。
- Hubの標準モデル・表示名・指示・無効化・削除がDesktopへ伝わる結合試験を追加しました。Main・Sub・Approveの生成経路、実行中の変更、未保存入力の保持、確認後の再実行も対象です。
- Hubの管理操作とDesktop／Runnerの境界について、GUI監査一覧を更新しました。試験の存在、実行結果、画像の目視、物理別PCの確認を分けて記録します。

Desktop 3.0.7との組合せでは、接続済みDesktopが変更を自動取得し、モデル選択の確認・保存を促します。開始済みのAI応答は開始時のモデルで完了しますが、その後の新しいAI要求は再確認まで停止します。実行済みの処理は元に戻りません。

Hubを停止し、ZIP全体を展開して `Setup-Hub.cmd` で更新してください。通常の更新では保存データを初期化しません。手順は[Windowsへの導入・更新・削除](../windows-setup.md)を参照してください。

今回の結合試験は同一Windows上の隔離環境で実施しています。固定応答による経路確認と実モデルの生成品質は別です。実OneDrive環境、物理別PC・組織ポリシー・全機能の全状態を確認済みとするものではありません。[ブラウザー監査一覧](../../tests/browser/coverage.md)に確認項目と不足条件を記載しています。
