# moyAI Hub v1.0.3

旧版からの更新時に管理画面を開けない問題と、長時間利用時・連続起動時の認証と起動処理を修正します。

- 旧配置のWindows受信許可が残っていても、既定保存先を移行して起動できます。新版の管理画面から、旧実行ファイルを使わずに対象ルールを確認・解除できます。
- 管理画面の8時間の認証制限を撤廃します。HubやPCの再起動後も利用でき、明示的な利用終了や権限・PC登録の取り消しは引き続き反映します。旧版の画面は更新後に起動入口から一度開き直してください。
- 初回移行時の同時起動を待ち合わせ、同じHubへ接続します。保存中の一時ファイルとの競合で起動できない問題も修正します。
- 同じブラウザータブをHub再起動後に開き直す場合と、連続した起動ticketの認証が重なる場合を修正します。
- Setupとスタートメニューからの起動失敗に、元のエラー内容とログの場所を表示します。

HubとGatewayを停止するかPCを再起動し、ZIP全体を展開して`Setup-Hub.cmd`を通常の権限で実行してください。自動起動で旧Hubが再開した場合は先に停止します。保存データの初期化は不要です。固定ポートの設定を保持し、空きポートへ自動変更しません。[更新手順](../windows-setup.md)と[旧受信許可の解除](../firewall.md)を参照してください。

障害が起きた別PCでの直接確認と、Windows自体の再起動試験は未実施です。隔離環境でのHub再起動・認証維持・同時起動と、実際のWindows受信許可解除を検証しています。
